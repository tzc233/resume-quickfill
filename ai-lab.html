🧪 本机模型自测(实验)

让模型只回答一件事:每个字段对应档案的哪一栏、第几段。这里用一组真实踩过坑的表单字段(只有标签,没有任何个人信息)量一下它认得准不准 —— 量完再决定要不要接进填表。门槛:错填 0 且准确率 ≥85%。

0. 选模型

先点「连通性自检」—— 只发一个字段,成功会显示模型原话,失败会显示服务商的真实错误(401 = Key 不对,402 = 余额不足,404 = 端点写错)。通了再跑整套评测。

⚠️ 选 API 就会产生网络请求:把你正在填的那张表的字段标签、模块标题、下拉选项发给服务商。页面上已有的值和你的档案内容一概不发。Key 只存在本机浏览器,不随备份导出。默认是本机模式,不填 Key 不会联网。
