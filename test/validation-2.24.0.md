# 2.24.0 本地验证记录

验证日期：2026-10-08。环境：macOS、Chrome 稳定版（Playwright `channel: 'chrome'`，headless）。

## 触发这一版的现场报告

建设银行校招（job2.ccb.com/cn/job/resume.html），引擎 2.23.0。

- 「识别到的区块标题」只有 `教育经历 新增教育经历收起 / 教育经历 1 / 教育经历 2`；
  逐字段表里**所有字段的区块列都是「教育」**，包括实习、项目、奖励荣誉三个模块。
- 项目模块：「所在单位」「经历描述」命中 `work.company / work.desc`，被分到「工作#3」
  （档案只有 2 段）—— 经历描述整栏没填。
- 奖励荣誉模块：7 个「奖励名称」一条规则都不收；它的候选里有记录头「奖励荣誉 1 取消 保存」。
- 同一页 v2 的能力图把 f203* / f311* / f313* 认成 work / projects / awards（v2 别名更宽），
  说明三个模块的标题在页面上，是 1.x 的别名表与排除逻辑没认出来。

## 根因

1. **别名表收不住**：「奖励荣誉」不在获奖别名里（报告原文可见）。实习、项目两个模块的标题
   报告没带出原文（只列出认出的标题），但 v2 用 `/实习|工作/`、`/项目/` 认得、1.x 的定长别名认不得。
2. **2.18.0 的「字段标签不算区块标题」太宽**：候选里只要含 `<label>` 就排除。选填模块的模块头常挂
   「暂无××经历」勾选框，整个模块头因此被丢掉。改为：`<label>` 就是候选全部文字时才算字段标签。
3. **区块认对之后暴露的错填**：项目块的「所在单位」按规则是工作单位，区块认对后会被灌进实习公司名。
   档案的项目没有「所在单位」，改为留空并说明。
4. **空表单上的错填**（现场因已有值未暴露）：「奖励名称」不收 → 退到记录头「奖励荣誉 1」→
   命中整段 `awards` 汇总，把奖项汇总灌进单条名称栏。
