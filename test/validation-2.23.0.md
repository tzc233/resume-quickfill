# 2.23.0 本地验证记录

验证日期：2026-10-07。环境：macOS、Chrome 稳定版（Playwright `channel: 'chrome'`，headless）。

## 为什么改

2.22.0 的「版本」只能覆盖措辞、事实只读共用。用户明确要的是**央国企一份、私企一份，各自独立维护** ——
事实、经历的增删都可以不同。2.22.0 的模型不合用，改为多份独立简历。

## 设计

- 存储：默认简历仍在 `profile`（`profile._name` 是名字；老版本、诊断、备份都认它），
  其余在 `altProfiles: { id: { name, profile } }`；附件：默认在 `resumeFile`，其余在 `resumeFiles[id]`。
- `versions.js`：`list / pick / factDiffs / migrate`，弹窗、档案页、注入页面的填充脚本共用；
  `pick` 返回去掉元数据的档案副本与**该简历自己的**附件。
- **附件不回退**：某份简历没传附件，填表时不注入，弹窗写明「未上传附件，这次不注入附件」。
  拿私企版 PDF 去投央国企比不注入更糟。
- **事实矛盾只提醒**：`factDiffs` 只比同一段经历（按名称对上）里两边都有值的事实栏；
  一边空着、只在一份里出现的经历、措辞差异都不算。档案体检里列出，点一条跳到那一栏。
- 档案页同时只编辑一份，其余放内存；切换时先收起当前页面，保存时一起写回，切换不丢改动。
- 新建简历复制当前这份的全部内容作起点，不复制附件。
- 2.22.0 的 `_v / versions` 结构：读到时按当时的合并规则展开成独立简历（档案页提示保存；
  弹窗在保存前就地按新结构读）。

## 回归

三组测试按新语义重写，均先在 2.22.0 代码上确认为红（`V.pick is not a function`、
弹窗列不出简历、档案页「新简历以当前内容为起点」失败）：

- `test/versions.html` 14 项：列出简历、取到各自全部内容、副本互不影响、附件不回退、未知 id 按默认、
  元数据不进引擎、事实矛盾能查出且「一边空 / 只一边有 / 措辞不同」不算、2.22.0 结构转换、无旧结构不转换。
- `test/popup-versions.cjs` 14 项：列出简历、按站点记住、引擎拿到所选简历的全部内容与附件、
  换站点回默认、**没传附件不顶替且弹窗说明**、只有一份时不显示选择器。
- `test/options-page.cjs` 第 10 节 15 项（共 57）：新建即复制、所有栏目可改且经历可增删、新简历不继承附件、
  事实矛盾体检提醒、两份分别落盘互不影响、附件分开存、切换回显、**切换不丢未保存改动**、删除清掉内容与附件。

结果：

- `node test/browser-runner.cjs <test/ 下全部夹具>`：**56 张夹具、776 项断言全部通过**。
- `node test/options-page.cjs` 57 项、`node test/popup-versions.cjs` 14 项、`node test/manual-learning.cjs` 11 组：全部通过。
- 1100px 与 390px 截图：无横向滚动。
