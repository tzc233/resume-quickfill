验证日期：2026-10-08。只改本机模型自测（`ai.js / ai-lab.js`），填表流程不变。

## 第一次实测（用户本机 Chrome 154，2.27.0）

准确率 70%（50/71）· **错填 5** · 漏答 16 · 51.2 秒 —— 未达接入门槛（错填 0、准确率 ≥ 85%）。

- 错填 5：是否为工商银行员工 → 父亲姓名、短信验证码 → 手机号、自我评价 → 姓名、籍贯 → 民族、最高学历 → 毕业年份。
  前两个属于插件硬规则本来就不填的类型；后三个是纯语义错误。
- 漏答 16：几乎全部落在建设银行与优必选两组里「一整批 8 个列表栏」的批次，同组后面的小批与其它组全对 ——
  更像长输出被截断、未作答的 id 默认成了 none，而不是看不懂。

## 调整

1. **硬规则先拦**（`guarded`）：标签或模块含验证码 / 密码 / 协议 / 隐私 / 声明 / 承诺 / 紧急联系人 / 推荐人 / 内推，
   或选项只有「是 / 否 / 有 / 无」的单选题，直接判 none，不交给模型 —— 接入填表时也是这样，量的才是真实情况。
2. **每批 4 个字段**（原 8 个）。
3. **系统提示加 7 个示范题**，标签全部不在评测集里（户口所在地、个人简介、公司 / 实践经历 2、就读院校、所获荣誉 / 荣誉 3、
   联系人与本人关系、民族），不泄露答案；并要求「每个 id 都要作答」。
4. **复制结果附原始输出**：有漏答或错填的批次，带上模型原始 JSON（截 600 字），分得清是截断还是理解错。
