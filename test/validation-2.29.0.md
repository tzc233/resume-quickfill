# 2.29.0 本地验证记录

验证日期：2026-10-08。环境：macOS、Chrome 稳定版（Playwright `channel: 'chrome'`，headless）。

## 需求

用户：「我填了硕士的那一堆学校、专业、时间，它应该自动会填本科的那一堆」——
学的应是「这一栏是什么」，而不是「这个空填什么」。原有填写记忆按「站点 + 标签（+ 同名序号）」原样重放值，换一段就不认。

## 设计（`engine-v2/discovery.js`、`learning.js`、`runtime.js`）

1. **反查栏目** `V2.profileMatch`：拿这次填充所用的简历（`V2.lastProfile`，填充时记下），把用户提交的显示值对到档案栏目。
   日期按年月比（「2024.09」「2024年9月」都对上 2024-09）；学历按层级比（硕士研究生 ↔ 硕士）；其它按相等或受控包含。
   **只在栏目类型唯一时学**：同一值出现在两段的同一栏没关系，出现在两个不同栏目（城市「上海」可能是现居也可能是期望）就不学。
2. **记录块** `V2.recordBlock`：往上找到「有同形兄弟」的祖先（控件标签序列相同），它在同形兄弟里的位置就是段号。
3. **立刻补兄弟块**：按「块位置 + (学到时的段号 − 学到时的块位置)」取档案对应记录，只写空栏；档案没有那一段就不写。
   日期照用户写法（`V2.dateFormat` 模板 `{y}.{mm}` 等）；下拉先用档案原值，配不上再按用户例子换算（`V2.variants`：加前后缀、去前导零），
   换算结果仍要是页面真实选项，适配器配不上就留空。
4. **记住规律**：存为 `site:<host>|sem:<标签>@<块形状哈希>`，下次填充在解析前载入（`V2.loadSemRows`），
   规则认不出的字段按「标签 + 块形状」认，段号按块位置换算（`V2.learnedSemHit`）。规则认得的字段不学、不改。
5. 只在**提交**（change / 选中下拉）时学，不在打字中途学；家庭成员一组、验证码类不学；
   学习前必须先点过一键填充（要用当次的简历反查）。档案页「填写记忆」显示为「规律：标签 = 栏目」，可删除。

本机模型自测：中文系统提示与英文系统提示各跑一遍，并排比较（用户指出：中文能不能用，直接拿中文问最准）。
