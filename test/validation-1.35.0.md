# 1.35.0 验证记录

2026-09-08，独立无界面 Chrome：31 张测试页、612 项断言全部通过。
测试资源均来自本地文件，没有访问真实招聘网站。

## 本次诊断改进

- “复制诊断报告”会对最多 14 个不同类型的空白日期、下拉和级联控件执行深度探测。
- 深度探测只打开和关闭控件，不选择选项、不写入字段。
- 记录每个触发目标、点击后的可见弹层、弹层结构、选项数量和短选项文本。
- 页面尚未点过“一键填充”时，也能采集日期和下拉的实际交互证据。
- 所有失败与未识别字段进入完整索引；详细 DOM 结构最多保留 60 份。
- 大赛、游戏、语言、技能、工作/项目时间等未识别字段附候选档案字段和档案段数。
- 自定义控件是否已有值改为读取真实组件值，避免仅凭内部文字误判。

## 新增验证

`deep-diagnostics.html` 包含 6 项断言：探测日期与大赛下拉、采集弹层结构和选项、记录大赛语义建议、不选择值、不写入值、探测后关闭弹层。

其余 30 张既有测试页全部通过，包括用户提供结构复现的中文月份面板测试。

## 边界

打开控件可能触发招聘页面自身的远程选项查询或前端校验提示。插件不发起网络请求，也不会在深度诊断中选择或写入字段。
真实网易页面的 React 事件和服务端保存仍需用 1.35.0 报告验证。
