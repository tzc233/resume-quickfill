# 1.34.0 验证记录

2026-09-08，独立无界面 Chrome：30 张测试页、606 项断言全部通过。
测试资源均来自本地文件，没有访问真实招聘网站。

## 诊断改进

- 所有失败和未识别字段进入“可执行诊断索引”，不受详细 DOM 片段数量限制。
- 日期控件记录点击目标、点击前后的可见弹层、面板类型、年份、导航结果、目标日期格和回读结果。
- 下拉控件记录触发层级、每次触发后的弹层、选项数量、脱敏后的选项摘要、匹配失败和提交失败阶段。
- 可见弹层保留最多 2,400 字符的脱敏结构，便于识别未知组件。
- 未命中字段附原因分类、可能的档案字段和对应档案段数。大赛名称、成绩和时间分别提示 `comp.name`、`comp.result`、`comp.date`。
- 详细结构采样从 24 份提高到 60 份，并优先保留产生过交互记录的失败字段。

## 验证

- `diagnostic-export.html`：6 项，覆盖完整失败索引、动作记录、语义建议和整份导出脱敏。
- `netease-month-real.html`：23 项，覆盖用户提供的中文月份结构、跨年、重复填写、禁用项、导航无响应和回读失败。
- `netease-safety.html`：4 项，覆盖排名映射、空下拉和外语/编程字段隔离。
- 其余既有回归页全部通过。

## 边界

诊断报告能记录浏览器页面中可见的 DOM 和事件结果，但不能读取 React 组件内部未暴露的状态，也不能证明服务端已经保存字段。
选项文本超过 16 字时仅记录长度；短选项保留文本，并继续接受整份报告的档案值脱敏。
真实网易页面仍需使用 1.34.0 生成一次报告，才能确认其具体时间和大赛控件分别停在哪个阶段。
