# 2.13.0 验证记录

2026-09-30，本地无头 Chrome：49 页 / 713 项断言。测试资源全部来自本地文件，未访问真实招聘网站。

## 现场证据与一处认知纠正

小鹏（飞书招聘）2.12.0 报告。学校名称已读到标签并由 2.x 填入，说明上一版的上溯修复生效。
但日期、获奖、语言仍未填。

报告中「学历」的 trace 第 4 次尝试，目标 class 为
`ud__select__selector ... ud__select__selector-open ...` —— 组件已处于展开状态，
而 options 为 0。此前所有版本都把这种情况报成「下拉点不开」，
排查方向因此一直是错的：问题不在触发，而在展开后读不到弹层里的选项。

## 本次修复

- 区块标题不再走写死的白名单。原判据是一张固定的区块名列表，飞书的「语言能力」
  不在表内，导致该块 8 个下拉全部 section 为空、域规则无法绑定、key 为 null，获奖同理。
  改为三条同时成立：文字长度不超过 10、能对上别名表、且该层只有这一个候选。
- 标签上溯的停手判据改为「这一层只有一个标签文本」。原判据是「本分支之外还有控件就停」，
  而起止日期是同一个表单项里的两个输入框，该条一触即发，标签尚未爬到即收手，
  日期因此完全没有标签、连规则都匹配不上。
- 下拉失败提示拆成两种：「组件已展开但读不到选项（弹层结构未知）」与「点不开」。

## 新增验证
