# 2.26.0 本地验证记录

验证日期：2026-10-08。环境：macOS、Chrome 稳定版（Playwright `channel: 'chrome'`，headless）。

## 触发这一版的现场反馈

工商银行申请表（用户贴出页面文字）：「父亲」一组的姓名框被写成本人姓名，「工作单位 / 工作职务」被写成
本人第 1 段实习的公司与职位；「母亲」一组同样是本人姓名 + 第 2 段实习。—— 父母被当成了两段工作经历。

## 根因

- 每位家人一组字段没有区块标题可依（不是「家庭成员」区块标题下，而是每组顶上一个「父亲」/「母亲」）。
  `BLOCK_SECTION` 只认「紧急联系人 / 亲属信息 / 家庭成员…」这类区块标题，拦不住。
- 组内标签是通用词：姓名框的占位「请输入姓名」→ `basic.fullName`；「工作单位 / 工作职务」→ `work.*`，
  页面上没有本人实习栏可占位时，档案的第 1、2 段工作就落进了父亲、母亲两组。

## 修改

| 修改 | 位置 |
| --- | --- |
| `familyOf`：自下而上找最小的一组（控件 ≤ 10，单选组按一组计），组里有节点的**自身文字**恰为称谓（父亲 / 母亲 / 配偶 / 兄弟姐妹 / 子女，可带「姓名 / 信息」后缀） | `content.js` |
| `familyHit`：组内字段按标签认角色（姓名 / 工作单位 / 职务 / 电话 / 政治面貌）；只按档案 `family` 里同称谓的成员取值，没有就留空并写明原因；单选 / 勾选不代答 | 同上 |
| 2.x：`V2.isFamily` 命中的控件不解析，交给 1.x | `engine-v2/discovery.js` |
| 档案页新增「家庭成员」列表（称谓、姓名、工作单位、职务 / 职业、联系电话、政治面貌）；模板加示例；多份简历的事实矛盾检查纳入家庭成员 | `options.*`、`profile-template.json`、`versions.js` |

## 回归

`test/family-members.html`（8 项，走完整的 `__RQF_V2.fill` 两条流水线）照贴出的文字复刻：
每位家人一组 =「父亲」姓名框（占位「请输入姓名」）+「是否为工商银行员工」是 / 否 +「工作单位」+「工作职务」。

- 改动前 8 项中 5 项失败；第零轮（页面上没有本人实习栏）完整复现现场：
  父亲 = 本人姓名 + 示例科技 + 示例实习生，母亲 = 本人姓名 + 示例游戏 + 示例算法实习生。
- 改动后：没有家庭成员档案时两组全空、本人信息照常；有档案时父亲、母亲各自对号入座；两轮都没代选单选。

`test/options-page.cjs` 新增 2 项（家庭成员按称谓落盘、段头显示称谓）。

结果：

- `node test/options-page.cjs` 59 项、`node test/popup-versions.cjs` 14 项、`node test/manual-learning.cjs` 11 组：全部通过。
