# 2.21.0 本地验证记录

验证日期：2026-10-07。环境：macOS、Chrome 稳定版（Playwright `channel: 'chrome'`，headless）。

## 这一版解决什么

2.20.0 之后，「手动填写记忆」仍有三处问题：

1. **黑箱**：用户看不到记了什么。弹窗只给「当前站点 N 条」和「清除当前网站」，
   2.20.0 之前误记在无关网站上的内容（搜索框、评论框）只能逐站打开再清。
2. **只增不减**：`rqfV2LearnedSelections` 没有上限，每次写入都整份读出再写回。
3. **好答案困在单站**：记忆按站点隔离（这是对的 —— 组件库相同不代表答案相同），
   但像微信号、政治面貌这类在任何网站都成立的答案，用户想推广时没有出路。

## 修改

| 修改 | 位置 |
| --- | --- |
| 档案页「填写记忆」区：按站点分组（条数、最近日期、已启用/疑似无关标记），逐条删除、清除整站、停用某站记忆 | `options.html / options.js / styles.css` |
| 「疑似无关」= 没点过一键填充 且 全部记录都是未识别输入框（`input:`）；一键清理前列出站点并确认 | 同上 |
| 「写进档案」：记忆路径与档案同名（`basic.wechat`、`education.0.degree`），只填空栏、不覆盖已有值；下拉要有对应选项、月份要是 YYYY-MM，否则按钮置灰并说明原因；只改表单，走正常保存 | 同上 |
| 「转为自定义问答」：未识别的填空题（年龄……）一键加为自定义问答，关键词为标签 | 同上 |
| 删除时先读最新存储再删，不覆盖其它标签页刚写入的记忆 | 同上 |
| 记忆上限 1500 条，超出先删 `updatedAt` 最旧的 | `engine-v2/learning.js` |
| 每条记忆带可读标签 `label`（键里的标签是归一化过的） | 同上 |

## 回归

- `test/learning-v2.html` 新增 4 项（可读标签、容量上限、超限删最旧、超限时新记的留下）：
  在改动前的 `learning.js` 上 13 项中 3 项失败（标签、上限、删最旧），改动后全绿。
- `test/options-page.cjs` 新增 17 项：两个站点的分组与标记、写进档案（文本与下拉）、
  已有值时不给覆盖、转为自定义问答、保存后落盘、删除单条、停用不删记忆、
  一键清理只清无关站点且先确认。改动前档案页没有这个区，首项即失败。
